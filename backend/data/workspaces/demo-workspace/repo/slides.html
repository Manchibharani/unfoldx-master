03 / The REST API

A small surface.
Clear operations.

The FastAPI service exposes a focused CRUD contract with validated task fields, filtering, search, and pagination.

GET/api/tasksFilter by status, priority, search, limit, and offset
POST/api/tasksCreate a task; validate title and priority
GET/api/tasks/{id}Fetch one task by identifier
PATCH/api/tasks/{id}Update selected task fields
DELETE/api/tasks/{id}Remove a task by identifier

04 / Confidence through tests

Protect the contract
at every step.

The test suite covers CRUD behavior, list filters and pagination, validation errors, missing IDs, and timestamp updates.

01 / CREATE
Valid input creates a task

Check the success response and returned task fields.

02 / READ
Filters and pages are correct

Combine status, priority, search, limit, and offset.

03 / UPDATE
Changes persist

Confirm a status or field update appears on a later read.

04 / ERRORS
Errors stay predictable

Reject invalid input and report missing tasks clearly.
